# Clinic Management System

## Overview
This project is a clinic management system developed for a software engineering course.
It helps clinics manage patients, appointments, and authentication efficiently.

## Functional Requirements
- Patients can register and log in
- Patients can book and view appointments
- Staff can manage patient records
- Secure authentication system

## Non-Functional Requirements
- User-friendly interface
- Secure data handling
- Scalable backend architecture

## Technologies Used
- Frontend: React / Expo
- Backend: ASP.NET Core
- Database: SQL Server
- Version Control: Git & GitHub

## Project Structure
- /app → Frontend UI
- /backend → Backend API
- /database → Database schema and ERD

## Version Control
This project uses GitHub for version control with feature-based commits
and clear commit messages to track development progress.
